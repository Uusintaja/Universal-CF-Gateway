# Agent–Human Collaboration Protocol

Start by reviewing the file tree below — it shows the current state and the role of each file. Then follow the steps in order.

```
agent-protocol/
├── COLLABORATION_PROTOCOL.md       — Phase markers, documentation rules,
│                                     truth hierarchy, update rules, anti-patterns
├── USER_PROFILE.md                 — Communication style + project preference
│                                     questionnaire (fill after asking the user)
├── ASSISTANT_ONBOARDING.md         — State index with reading priority
├── PAT_GUIDE.md                    — Optional: GitHub PAT push workflow
├── project-context/                — Project-specific files (already filled)
└── ABOUT.md                        — Human-readable overview and setup guide
```

## Protocol

1. Read `COLLABORATION_PROTOCOL.md`.
2. Read `USER_PROFILE.md`; confirm the communication style with the user.
3. Read `ASSISTANT_ONBOARDING.md`, then follow its reading priority.
4. During the first conversation, ask the user the questions in `USER_PROFILE.md` §2–4 and record the answers.
5. If you need to push commits, follow `PAT_GUIDE.md`.
